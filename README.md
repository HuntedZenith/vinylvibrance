# Vinyl Vibrance

A vanilla-friendly Fabric mod that expands Minecraft's music disc collection with new musics discs that integrate naturally into survival gameplay. 

## Features

- New music discs
- Vanilla-style loot integration
- New armor trims (Notes, Record, and Waves)
- Disc duplication through the Record Engraver

## Installation

1. Install Fabric Loader
2. Install Fabric API
3. Place this mod in your `mods` folder

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API

## Planned Features

- Disc duplication generations

## Known Issues

- Custom jukebox songs currently inherit Minecraft's infinite-range bug. (Custom music discs can be heard from any distance due to a bug.)
